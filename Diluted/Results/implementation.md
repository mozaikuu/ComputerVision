Implementation
The model was implemented in Python using deep learning libraries on GPU-equipped hardware. Following related work, we used Keras with the TensorFlow backend (e.g. TensorFlow-GPU) under Python 3.12. In one setup, training was performed on a Windows 11 machine with an Intel Core i7-8700 CPU, NVIDIA GeForce RTX 2060 (16 GB) GPU and 32 GB RAM. (In other experiments we used Google Colab with a NVIDIA Tesla K80 (12 GB) GPU.) The chest X-ray dataset (∼5,856 images from the Kaggle collection) was split into training/validation/test sets as in prior work. Images were resized to 224×224, normalized, and augmented using standard techniques (random flips, rotations, scaling, brightness and color adjustments) to mitigate class imbalance. Training hyperparameters were chosen empirically. We fine-tuned the VGG16 base (pretrained on ImageNet) by replacing its final fully-connected layer with a new binary-output layer. A constant learning rate (e.g. 0.001) was used with the Adam (or SGD) optimizer. The network was trained for up to ~60 epochs with a batch size of 64, early stopping on validation loss, and standard L2 regularization/dropout to prevent overfitting. For the GA optimization, we encoded each candidate CNN configuration as a “chromosome” (e.g. layer counts or filter sizes) and ran the genetic search for dozens of generations with population sizes on the order of 10–50. Typical GA parameters were crossover probability ≈0.8 and mutation rate ≈0.1. In each generation, model variants were trained for a few epochs and evaluated on the validation set; the fitness was based on classification accuracy. The best individual at termination was selected as the final model. Overall training (including GA search) required on the order of hours on the GPU hardware mentioned above.
